2.4 · Один агент — одна задача

🎯 Без кода · ✅ Интерактивный квиз · ⏱️ ~10 минут

🎯 Зачем это бизнесу

Договор задачи готов: есть предусловие, постусловие, инварианты. Остался один соблазн, который ломает всё сразу: «А давай за один раз — сравни цены, напиши письмо поставщику и подготовь презентацию для руководства». Экономия на бумаге, убыток в работе.

Правило называется коротко: одна задача до готовности. В инженерных текстах — WIP = 1 (work in progress, «в работе — одна»). Смысл один: следующая задача начинается после приёмки предыдущей.

📚 Что изучаем

Почему «всё сразу» режет качество каждой части

Что происходитСледствие
Контекст размывается между тремя задачамиЦифры из сравнения цен «просачиваются» в письмо; постусловия путаются
Ошибка в первой части сыплется в остальныеНеверная цена доезжает до презентации для руководства
Не проверить часть отдельноНет базовой линии: результат — комок из трёх «почти готово»
«Готово» становится неопределённымВернуться к уроку 0: слово вместо факта — но уже на уровне задач

С людьми то же самое — но агент делает это быстрее и увереннее. Параллельные задачи для него не страховка, а три источника уверенных ошибок.

Симптомы перегруженного агента

  • Результат «почти весь»: 8 из 10 позиций, два текста из трёх
  • Мелкие противоречия между частями: в таблице одна цифра, в выводе — другая
  • Агент «забыл» часть поручения — оно просто потерялось между другими
  • Проверять нечем: сверять надо всё сразу, а не частями

Очередь вместо связки: как отдавать несколько задач

Не: «Сделай A, B и C за один раз»
А: очередь из одной задачи.

Порядок простой:
1. Задача A с постусловием → приёмка (урок 0.3)
2. Запись в ПРОГРЕСС.md: A принята, факты в файл
3. Контрольная точка (урок 1.4) — если B меняет файлы A
4. Задача B с постусловием → приёмка
5. И так далее

Мелкие независимые поручения («переименуй файлы по шаблону»)
можно связкой. Скоординированные части одного результата — нет.

Граница правила

Это не про «никогда не давай двух задач». Это про один результат: если части работы складываются в один артефакт (отчёт, пакет документов, кампания) — ведём их по очереди с контрольными точками между ними. Если поручения независимы и мелки — связка допустима, но каждое со своим постусловием.

🛠️ Как применить

📢 Маркетинг

Кампания из шести текстов: не «напиши все шесть», а очередь. Текст 1 принят (постусловие: до 500 знаков, призыв из брифа) → текст 2. К концу недели — шесть принятых текстов вместо шести черновиков «на доработке».

🛒 Закупщик

«Сравни КП и подготовь рекомендацию руководству» — две задачи: сначала таблица с постусловием (все позиции, источники), приёмка, потом рекомендация, которая опирается на принятую таблицу. Рекомендация на недопроверенной таблице — риск из урока 0 в чистом виде.

🧑‍💼 Руководитель проекта

Правило команды: «агент берёт следующую задачу из очереди только после записи о приёмке предыдущей в ПРОГРЕСС.md». Очередь видна всем, «что сейчас в работе» — одна строка.

✅ Чеклист принятия результата

  • У агента никогда не больше одной непринятой задачи
  • Скоординированные части одного результата иду по очереди с точками между ними
  • Каждая задача в очереди имеет своё постусловие
  • Приёмка каждой части зафиксирована в ПРОГРЕСС.md до старта следующей

📝 Проверка понимания

Вопрос 1: Что означает правило «один агент — одна задача»?

A) Агенту нельзя давать более одной задачи в день
B) Следующая задача начинается после приёмки предыдущей; в работе — одна
C) Нужен отдельный агент на каждую задачу

Вопрос 2: «Сравни КП, напиши письмо и сделай презентацию» — как правильно поручить?

A) Одним сообщением — агент сам разберётся с приоритетами
B) Очередью: сравнение с постусловием → приёмка → точка → письмо на основе принятой таблицы → приёмка → презентация
C) Сначала презентация, чтобы был план

Вопрос 3: Какие поручения можно давать связкой?

A) Мелкие и независимые, каждое со своим постусловием
B) Любые, если нет времени
C) Никакие, связка всегда запрещена

🎯 Главное из урока

«Всё сразу» — это три уверенные ошибки вместо одной проверенной задачи. Очередь из одной задачи с приёмкой и точками между частями — тот же объём работы, но каждая часть настоящая. Уровень 2 закончен: теперь задача — это договор с началом, концом и правилами без исключений.
