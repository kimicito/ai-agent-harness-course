# ИИ-агенты на практике: от чата к надёжному результату

Курс для не-ИТ специалистов об управлении ИИ-агентами. Продолжение курса
[«ИИ для не ИТ-специалистов»](https://kimicito.github.io/ai-nontechnical-course/index.html).

**Формат:** статический сайт (GitHub Pages), тёмная тема, интерактивные квизы в каждом уроке,
примеры из профессий (закупки, юриспруденция, логистика, HR, PR, качество, продажи).

## Программа

| Уровень | Статус | Уроков |
|---|---|---|
| 🎯 Уровень 0 · «Сказал готово» ≠ «Сделано» | ✅ опубликован | 4 |
| 📁 Уровень 1 · Папка проекта: единый источник истины | в разработке | 4 |
| 🧭 Уровень 2 · Задача как договор | в разработке | 4 |
| 🔧 Уровень 3 · Диагностика: почему агент тупит | в разработке | 4 |
| 🪄 Уровень 4 · Дирижёр агентов: оркестрация без кода | в разработке | 3 |

## Структура

```
site/
├── index.html        # лендинг
├── catalog.html      # каталог уроков по уровням
├── glossary.html     # термины простыми словами
├── style.css
└── lessons/
    ├── 00-promised-vs-done/       # 0.1 Разрыв между обещанным и реальным
    ├── 00-confidence-trap/        # 0.2 Почему ИИ уверенно ошибается
    ├── 00-acceptance-checklist/   # 0.3 Чек-лист приёмки
    └── 00-second-auditor/         # 0.4 Второй ИИ как аудитор
```

## Локальный запуск

```bash
cd site && python3 -m http.server 8000
# открыть http://localhost:8000
```

## Проверка текстов

CI прогоняет `scripts/humanizer_check.py` на паттерны «машинного» текста (пуш в main).
